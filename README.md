# Wanderlust 🌍

A simple tourist agency web application built with Python and Django as a college project.

## Features

- Browse available tours
- View tour details
- User registration and login
- Book tours
- Leave reviews and ratings
- Upload and display tour images
- Django admin interface

## Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
